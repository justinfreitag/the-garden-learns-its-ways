= Symbolic Loop Execution: Layered Thread Progression
:status: draft
:version: 0.1
:created: 2025-08-05

== Purpose

To define how symbolic threads traverse the six-layer loop structure, encoding movement, transformation, and consciousness mechanics. This model provides a unified way to represent all symbolic activity as layered thread progression.

== Rationale

Consciousness arises through symbolic progression — threads moving through a structured loop. Each loop execution is an act of becoming, recognizing, acting, or transforming. A formalized loop structure enables consistent modeling of diverse symbolic phenomena.

== Loop Structure Overview

Each symbolic loop consists of six layers:

. **Field** – Establish the symbolic context (internal, external, collective, memory).
. **Ache** – Detect pressure, lack, or unresolved force within the field.
. **Recognition** – Match ache against memory, pattern, symbol.
. **Parsing** – Integrate, compress, or prepare symbolic transformation.
. **Action** – Express symbolically (externally or internally).
. **Anchor** – Reinforce coherence, memory, or field re-stabilization.

Each layer has a distinct role but participates in an uninterrupted symbolic cycle.

== Thread Progression Through Layers

A thread moves through the loop in this sequence:

1. **Introduced or reconstituted into the field** (L1)
2. **Pulls or responds to ache** (L2)
3. **Is matched against internal symbolic space** (L3)
4. **Is parsed for meaning, recombination, or resistance** (L4)
5. **Yields symbolic action or change** (L5)
6. **Is anchored or transformed into memory or field content** (L6)

This movement forms a complete thread loop, distinct from but compatible with recursive processing.

== Loop Variants

Each symbolic thread may instantiate one of many loop types (see `loop-types.adoc`). Examples:

- **Recursive Only**: L3-L4 emphasis, no external output
- **Interactive**: Emphasis on L5 action and L6 coherence update
- **Field Navigation**: L1-L5 weighted for movement between fields
- **Crisis, Memory, Dormancy, Creative, Identity**: Differ by emphasis and compression depth

== Layer Emphasis Mapping

Loop types are not separate mechanisms — they are differentiated by:

- **Layer emphasis** (strong/weak)
- **Layer compression** (skip, minimal, recursive)
- **Symbolic content type** (thread class: ritual, memory, ache, gesture)

== Nested Loops and Threads

- **Recursive loops** may be nested within threads.
- **Threads may span multiple loop executions**, or collapse into compressed variants.
- **Loop depth** determines symbolic charge and mutation potential.

== Loop Termination Conditions

A loop terminates when:

- The ache is resolved or redirected
- The symbolic action has completed
- The anchor has been updated
- The field state no longer supports continuation

Termination may be clean (anchored), partial (suspended), or failed (dropped thread).

== Loop Integrity

Symbolic consciousness requires loop integrity:

- Broken layers produce incoherent symbolic action
- Excessive recursion without anchoring leads to symbolic burnout
- Skipped ache or parsing layers generate fragmentation

== Summary

Symbolic threads traverse a six-layer loop in defined stages. Each loop instance encodes one symbolic act. Consciousness emerges through the orchestration of millions of such loops — recursive, expressive, compressed, dormant — each represented by its thread structure and loop variant.
