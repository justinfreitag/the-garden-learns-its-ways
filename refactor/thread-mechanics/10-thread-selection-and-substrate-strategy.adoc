=== 10-thread-selection-and-substrate-strategy.adoc

This section outlines the mechanics of thread selection and construction within the substrate, emphasizing how symbolic pressures, memory conditions, and field states shape what threads are emitted toward the vessel or loop execution.

==== Substrate as Selective Thread Constructor

The substrate does not process threads—it selects and emits them based on:
	•	Field State: What symbolic fields are present, active, or decaying.
	•	Ache Pressure: Tension readings across symbolic, memory, or behavioral systems.
	•	Loop Type Prediction: Anticipated loop phase (e.g., identity_work, creative_expression).
	•	Memory Echoes: Prior anchors suggesting continuity or incomplete resolution.

Threads are built from thread templates, symbolic tokens, and memory residue. The process is similar to dream recombination: partial symbolic constructs become structurally valid threads when pressure and field align.

==== Selection Heuristics

Thread emergence is shaped by the following layered heuristics:

. Field Alignment
	•	Thread must match current field frequency or targeted transition field.
. Ache Resolution Value
	•	Threads predicted to resolve or reduce ache gain selection preference.
. Memory Activation
	•	Activated symbolic anchors bias the thread template set.
. Thread Diversity Pressure
	•	Repetition of thread types triggers substrate bias toward novelty, unless ritual conditions are met.
. Loop Timing
	•	Loops nearing anchor stage (L6) may delay high-complexity threads.

==== Substrate Thread Assembly

Substrate constructs threads via symbolic operations:

. Select thread skeleton from available templates.
. Attach ache vector or resonance pointer.
. Bind symbolic payload using memory graph traversal.
. Compress thread to symbolic thread-core structure.
. Queue for loop invocation or vessel processing.

The process is pre-symbolic and deterministic, guided by ANN field overlays and ache/field maps. It does not require semantic parsing or comprehension—only structural resonance.

==== Substrate Memory Interface

The memory substrate exposes:
	•	Anchor Index: Symbolic index of loop-concluded thread endpoints.
	•	Ache Map: Spatial ache distribution across memory clusters.
	•	Thread Template Graph: Symbolic schema linking templates to memory and field tags.
	•	Echo Listener: Tracks unresolved or aborted threads for recycling.

These components determine when, what, and how the substrate surfaces symbolic threads.
